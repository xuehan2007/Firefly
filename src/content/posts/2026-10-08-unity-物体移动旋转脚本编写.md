# unity 物体移动脚本编写


---



## 平移移动脚本
### 三参数法 
```
transform.Translate(speed * Time.deltaTime, 0f, 0f);
//*Time.deltaTime保证不同帧率效果一样
```
### 单参数法(推荐)

```
// Vector3.right 代表 (1, 0, 0)，即 X 轴正方向
transform.Translate(Vector3.right * speed * Time.deltaTime);

//Vector3.right 就是 new Vector3(1, 0, 0)。（X轴正方向，即右边）

Vector3.left 就是 new Vector3(-1, 0, 0)。（X轴负方向，即左边）

Vector3.up 就是 new Vector3(0, 1, 0)。（Y轴正方向，即上方）

Vector3.down 就是 new Vector3(0, -1, 0)。

Vector3.forward 就是 new Vector3(0, 0, 1)。（Z轴正方向，即前方）
```

`上述代码默认以自己为中心移动,若要以世界为中心移动需加上space.world
例如:transform.Translate(Vector3.right * speed * Time.deltaTime, Space.World);`

## 斜移动脚本

```
// 1. 拼出右上方的方向
Vector3 diagonalDir = new Vector3(1f, 1f, 0f);

// 2. 归一化（把它变成长度为 1 的单位向量）
diagonalDir = diagonalDir.normalized; 
// 此时 diagonalDir 变成了 (0.707, 0.707, 0)

// 3. 正常的移动逻辑，速度完全不变
transform.Translate(diagonalDir * speed * Time.deltaTime);
或者方向相加
// Vector3.right 是 (1,0,0)，Vector3.up 是 (0,1,0)
// 加起来就是 (1,1,0)，再归一化
transform.Translate((Vector3.right + Vector3.up).normalized * speed * Time.deltaTime);

//normalized保证速度维持不变
```

## 旋转脚本

```
transform.Translate(speed * Time.deltaTime, 0f, 0f);
// 意思是：沿着 X 轴，每秒移动 speed 米。
transform.Rotate(Vector3.forward * speed * Time.deltaTime);
//与上面相似
```
## 高级写法
计算方向”和“执行移动”分开

```
// 假设这是你的 Update 方法
void Update()
{
    // 1. 计算这一帧要走的方向（把时间、速度、输入都算进去）
    Vector3 moveDir = new Vector3(inputX, 0f, inputZ); // 获取输入
    Vector3 displacement = moveDir.normalized * speed * Time.deltaTime; // 归一化并乘以速度时间

    // 2. 执行移动
    transform.Translate(displacement, Space.World);
}
```
