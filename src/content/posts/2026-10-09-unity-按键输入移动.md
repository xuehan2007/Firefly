# unity 按键输入移动


---


旧版输入系统（Input Manager）给了两类读法，回答的是两种不同的问题：
写法	回答的问题	典型用途

Input.GetKey(KeyCode.W)	这一帧键按着吗（按住期间一直为真）	持续按住往前走

Input.GetKeyDown(KeyCode.Space)	这一帧刚按下吗（只有按下的那一帧为真）	跳跃、开火这类一次性动作

Input.GetAxis("Horizontal")	这根轴的值是多少（静止 0，左/右 −1 到 +1，带平滑过渡）	平滑的移动输入

    GetKey 问的是「键」：参数是具体的键，键盘上每个键都能问。
    GetAxis 问的是「轴」：参数是轴的名字，左右两组键先被 Input Manager 折算成一个 −1 到 +1 的数。

轴名从哪来：菜单 Edit > Project Settings > Input Manager，里面有 Axes 列表。工程默认配好了 Horizontal（左右）、Vertical（前后）、Jump（空格），对照如下：

键盘按键	轴名（Axes）	读到的值
← →	Horizontal	左 −1、右 +1、松开 0
↓ ↑	Vertical	后 −1、前 +1、松开 0
空格	Jump	按住 1、松开 0

轴名必须和配置逐字一致：代码写 "Horizontal"，配置里也得叫 Horizontal，多一个字母少一个字母都读不到。
## 简单按键移动脚本


```c#
using UnityEngine;

public class InputDemo : MonoBehaviour          // 挂在对象上的脚本
{
    public float moveSpeed = 5f;               // 每秒移动 5 格；想慢一半就改成 5 / 2

    void Update()                              // 每帧问一次输入的地方
    {
        // 第 1 段 · 读：拿到这一帧的方向值
        float h = Input.GetAxis("Horizontal"); // 左右：−1 ~ +1
        float v = Input.GetAxis("Vertical");   // 前后：−1 ~ +1

        // 第 2 段 · 判：空格刚按下的那一帧才进来一次
        if (Input.GetKeyDown(KeyCode.Space))
        {
            Debug.Log("跳跃！");               // 先用日志确认输入真的进来了
        }

        // 第 3 段 · 动：把方向值变成位置变化
        // 新位置 = 旧位置 + 方向 × 每秒速度 × 本帧间隔秒数
        transform.position = transform.position
            + new Vector3(h, 0f, v) * moveSpeed * Time.deltaTime;
    }
}
```
