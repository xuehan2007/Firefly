# 小球按键移动+相机跟随
## 方法一:手写脚本
### 小球按键移动脚本

最简单版本
```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class MoveControl : MonoBehaviour
{
    public float speed = 5f;
    private Rigidbody rb;

   
    void Start()
    {
        rb = GetComponent<Rigidbody>();// 获取物体身上的刚体组件
    }

   
    void FixedUpdate()
    {
        float moveHorizontal = Input.GetAxis("Horizontal");
        float moveVertical = Input.GetAxis("Vertical");

        Vector3 movement = new Vector3(oveHorizontal, 0.0f, moveVertical);

// 给刚体施加一个力，方向是 movement，大小是 speed
        rb.AddForce(movement * speed);
    }
}
```
### 改进版本

```c#
using UnityEngine;

[RequireComponent(typeof(Rigidbody))] // 自动帮你加刚体，防止忘记
public class MoveControl : MonoBehaviour
{
    [Header("移动参数")]
    public float moveForce = 15f;      // 推力大小（建议比原来的5大一些，刚体推力需要稍大）
    public float maxSpeed = 6f;        // 最大移动速度
    public float stopForce = 10f;      // 松开按键后的刹车力（防止滑太远）

    private Rigidbody rb;
    private Vector3 inputDirection;    // 缓存输入方向

    void Start()
    {
        rb = GetComponent<Rigidbody>();
    }

    void Update()
    {
        // 1. 在 Update 里读输入（保证不漏按键）
        float h = Input.GetAxisRaw("Horizontal"); // 用 GetAxisRaw 手感更干脆，没有平滑过渡
        float v = Input.GetAxisRaw("Vertical");
        
        // 2. 组合方向并归一化（解决斜着走更快的问题）
        inputDirection = new Vector3(h, 0f, v).normalized;
    }

    void FixedUpdate()
    {
        // 3. 在 FixedUpdate 里做物理操作
        if (inputDirection.magnitude > 0.1f) 
        {
            // 有输入时施加推力
            rb.AddForce(inputDirection * moveForce, ForceMode.Force);
        }
        else
        {
            // 没有输入时，逐渐刹车（防止无限滑行）
            rb.linearVelocity = Vector3.Lerp(rb.linearVelocity, new Vector3(0, rb.linearVelocity.y, 0), stopForce * Time.fixedDeltaTime);
        }

        // 4. 限制最大水平速度（防止越滚越快）
        // 获取水平方向的速度
        Vector3 horizontalVelocity = new Vector3(rb.linearVelocity.x, 0f, rb.linearVelocity.z);
        
        if (horizontalVelocity.magnitude > maxSpeed)
        {
            // 如果超速，把水平速度钳制在 maxSpeed，保留 Y 轴速度（重力/跳跃用）
            Vector3 limitedVelocity = horizontalVelocity.normalized * maxSpeed;
            rb.linearVelocity = new Vector3(limitedVelocity.x, rb.linearVelocity.y, limitedVelocity.z);
        }
    }
}
//Interpolate（插值）：必须设为 Interpolate（不设的话，滚球在视觉上会一卡一卡的，相机跟随也会跟着抖）。

Collision Detection（碰撞检测）：如果小球滚得快，设为 Continuous Dynamic（防止穿墙）。

Constraints（约束）：
勾选 Freeze Rotation X 和 Freeze Rotation Z（防止小球像真球一样乱转方向）。

如果是在平地上，勾选 Freeze Position Y（防止小球飘起来）。
```

# 方法二:使用CameraChine
## 一、安装 Cinemachine
在 Unity 顶部菜单栏，点击 Window → Package Manager。

在打开的窗口左上角，将下拉菜单从 Packages: In Project 切换为 Unity Registry（或 All packages）。

在搜索框中输入 Cinemachine。

在列表中找到它，点击右下角的 Install 按钮。

安装完成后，顶部菜单栏会出现 Cinemachine 菜单，GameObject 菜单中也能创建虚拟相机了。

版本提示：Unity 6（6000.0）及以上版本使用的是 Cinemachine 3.x；老版本（2022 及以前）使用的是 2.x。两者界面略有不同，但核心逻辑一致。

## 二、添加 Cinemachine Brain（相机大脑）
Cinemachine Brain 是所有虚拟相机的“总控中心”，它负责管理所有虚拟相机，并将最终效果应用到主相机上。

在层级窗口（Hierarchy）中，选中 Main Camera。

在 Inspector 面板中，点击 Add Component。

搜索并添加 Cinemachine Brain。

添加后，你会看到 Main Camera 的 Transform 被锁定为只读——因为 Cinemachine 会接管相机的位置和旋转，你不需要手动调整了。

## 三、创建虚拟相机（Virtual Camera）
虚拟相机是 Cinemachine 的核心，它代表一个“镜头预设”。你可以在场景中创建多个虚拟相机，通过优先级切换它们。

在顶部菜单栏选择 Cinemachine → Create Virtual Camera（或右键层级窗口 → Cinemachine → Virtual Camera）。

Unity 会生成一个名为 CinemachineCamera 的对象，它自带 CinemachineVirtualCamera 组件。

## 四、设置跟随目标（核心步骤）
选中刚创建的虚拟相机，在 Inspector 中找到两个关键属性：

Follow：相机跟随哪个物体移动。把你的 ball 拖入这个槽位。

Look At：相机始终看向哪个物体。同样把 ball 拖入。

对于你的滚球场景，Follow 和 Look At 都设为小球即可。

## #五、配置 Body 算法（决定相机如何跟随）
虚拟相机的 Body 区域控制相机的位置行为。对于你的斜俯视滚球场景，推荐使用 Framing Transposer（Unity 6 中为 Position Composer），它专为 2D 和俯视/斜视相机设计。

在 Body 下拉菜单中选择 Framing Transposer，然后设置：

1. Follow Offset（跟随偏移量）
这是相机相对于小球的固定偏移。对于斜俯视视角，建议设置为类似 (0, 10, -8) 的值——Y 轴 10 表示相机在球上方 10 个单位，Z 轴 -8 表示相机在球的后方 8 个单位。

你可以在 Scene 视图中一边拖动虚拟相机的 Transform 调整角度，一边观察 Game 视图中的效果，调到满意后把 Transform 的 Position 填到 Follow Offset 中。

2. Camera Distance（相机距离）
控制相机与目标在 Z 轴上的距离，微调画面大小。

3. Damping（阻尼）—— 最关键参数
Damping 决定相机跟随的“松紧程度”。数值越小，相机越紧跟目标；数值越大，相机越迟钝、越平滑。 


阻尼值太小（比如 0）时相机是瞬间跟随，会有很强的“粘在球上”的感觉；阻尼值太大（比如 5 以上）时相机会严重滞后，球都跑远了相机才跟上。

## 六、配置 Aim 算法（可选）
Aim 区域控制相机的旋转行为。对于你的俯视滚球场景，如果相机角度是固定的（斜俯视），可以不做额外设置，或者将 Look At 留空，直接在虚拟相机的 Transform 中设置固定的旋转角度。

如果你希望相机始终“看向”小球，可以保留 Look At 的引用，并将 Aim 算法设为 Composer 或 Rotation Composer。

## 七、多相机切换（进阶）
当你以后需要切换视角（比如从跟随视角切到过场动画视角），可以利用 Priority（优先级） 来控制：

每个虚拟相机都有一个 Priority 值，默认是 0。

数值最高的虚拟相机会成为“Live”相机，控制主相机。

想让某个相机生效，把它的 Priority 设高即可（比如设为 10）；想切回跟随相机，把跟随相机的 Priority 设回更高值。

比如：

跟随相机 Priority = 10

过场动画相机 Priority = 20（平时禁用 GameObject，需要时启用）

##八. 注意事项
如果是旋转物体 
Look At：留空（设置为 None）。（这一步是为了不让相机时刻死盯着球心，防止相机跟着球的角度转）
在 Body 下拉菜单，选择 Framing Transposer（Unity 6 里叫 Position Composer）。

展开 Body 设置，找到 Binding Mode（绑定模式）：

把默认的 Lock To Target 改成 World Space（世界空间）。（这一步告诉相机：只看小球的世界坐标位置，完全无视小球的自身旋转！）

找到 Follow Offset（跟随偏移量）：

设置为 X: 0, Y: 10, Z: -8（根据你的桌子大小微调，这代表相机在斜上方俯视）。
